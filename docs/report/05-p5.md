# Problem 5 — Fan-out event distribution (pub/sub)

## Ringkasan

Aggregator menerbitkan `HazardEvent` ke topic Kafka `hazard.events` (transactional outbox + relay). Dua consumer independen (`dashboard-updater`, `notifier`) subscribe dengan consumer group berbeda, deduplikasi pada `event_id`, commit offset setelah proses.

## Bukti

- `make demo-p5` → `docs/evidence/p5/latest.log`
- Producer: `services/aggregator/internal/relay`, `internal/adapters/kafka`
- Consumer: `services/consumer-hazard/` (dua container di Compose)

## Semantik

At-least-once; idempotensi consumer lewat `event_id` (`hazard_id:version`).
